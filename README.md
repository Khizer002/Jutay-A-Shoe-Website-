# Jutay 👟 — A Shoe E-Commerce Website

A modern, fully responsive shoe shopping website built with React and Material UI. Clean design, smooth experience, and everything you'd expect from an online shoe store — product listings, cart, and checkout.

🔗 **Live Demo:** [shoe-website-chi.vercel.app](https://shoe-website-chi.vercel.app)

---

## What it does

- Browse a collection of shoes with a clean product listing page
- Add items to cart and manage them easily
- Checkout flow with a smooth UI
- Fully responsive — looks good on mobile, tablet, and desktop
- Material UI components throughout for a polished, consistent look

---

## Why I built this

Wanted to get comfortable with Material UI and build something that actually looks like a real e-commerce store rather than a plain tutorial project. Focused a lot on the UI/UX side — getting the layout, spacing, and component design right.

---

## Tech Stack

| Technology | Usage |
|------------|-------|
| React | UI and component structure |
| JavaScript | Core logic |
| Material UI (MUI) | Component library and styling |
| React Router DOM | Page navigation |
| Vite | Build tool and dev server |
| CSS | Custom styling on top of MUI |

---

## How to run it locally

```bash
git clone https://github.com/KhizerAhmad/Jutay-A-Shoe-Website.git
cd Shoe-Website
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.
